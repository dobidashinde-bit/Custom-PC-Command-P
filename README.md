# 🖥️ Custom PC Command Pad

A modern **web-based PC Command Pad** built with **HTML, CSS, and JavaScript**.

The project provides a centralized dashboard where users can quickly access frequently used applications, websites, and keyboard shortcuts from one clean interface.

> **Note:** The current version is a frontend web interface. Launching Windows applications such as Blender, VS Code, or DaVinci Resolve directly from the browser requires a local Python backend, which can be added in a future version.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Enter the project folder

```bash
cd Custom-PC-Command-Pad
```

### 3. Open in VS Code

```bash
code .
```

### 4. Run the website

You can open `index.html` directly in your browser.

For development, using **Live Server** in VS Code is recommended.

## 🎯 Project Goal

The goal of **Custom PC Command Pad** is to create a centralized control panel for Windows users.

Instead of opening different applications and websites separately, users can access their frequently used tools from a single interface.

The final version will combine:
